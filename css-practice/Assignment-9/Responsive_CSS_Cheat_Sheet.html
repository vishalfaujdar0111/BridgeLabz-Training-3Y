Responsive CSS Cheat Sheet

Filters

Modify the visual appearance of an element.

filter: grayscale(100%);

Media Queries

Apply CSS rules according to screen conditions.

@media (max-width: 700px) { ... }

Responsive Design

Make a webpage adapt to different screen sizes.

width: 100%; max-width: 1100px;

Typography

Use relative units for flexible text sizes.

font-size: clamp(1rem, 2vw, 1.5rem);
