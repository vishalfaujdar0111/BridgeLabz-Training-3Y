Responsive Design Principles

Fluid Layouts

Layouts use flexible sizes so content can adapt to available space.

width: 100%; max-width: 1100px;

Flexible Media

Images and other media should shrink within their containers.

img { max-width: 100%; height: auto; }

Breakpoints

Media queries change layouts when the screen reaches a chosen size.

@media (max-width: 600px) { ... }

Core concepts of responsive web design
