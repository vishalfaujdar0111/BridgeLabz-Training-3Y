Responsive Design

Responsive design uses flexible layouts, media queries, responsive typography, and flexible media so a webpage can adapt to different screen sizes.

Cheat Sheet

  • Grid – two-dimensional layout
  • Flexbox – one-dimensional layout
  • Media Queries – breakpoint rules
  • Clamp – flexible typography
