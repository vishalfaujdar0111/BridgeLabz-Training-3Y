# Assignment 10 — Bootstrap

This folder contains 10 separate solutions. Each question has its own `index.html` and `style.css`.

## Run
Open any question folder and open `index.html` in a browser.

- question2 — Personal Portfolio
- question3 — Product Catalog
- question4 — Restaurant Menu
- question5 — Custom Themed Blog
- question6 — Notifications Dashboard
- question7 — Task Tracker with Badges
- question8 — Pricing Plans
- question9 — Blog Pagination & Pager
- question10 — Travel Agency Carousel & Progress Bar

Bootstrap 5 is included through CDN. JavaScript is only included where Bootstrap components require it.
