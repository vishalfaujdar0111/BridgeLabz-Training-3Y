JAVASCRIPT ASSIGNMENT 2 (LECTURE 4–6)

This folder contains 10 separate JavaScript files, one for each question.

How to run:
1. Open Terminal in this folder.
2. Run any question with: node Q1_Scope_Conflict_Resolver.js
3. Replace the filename with the question you want to test.

You can also paste each file's code into the browser developer console.

All solutions use plain JavaScript and built-in language features only.
