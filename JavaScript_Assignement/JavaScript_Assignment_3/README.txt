JAVASCRIPT ASSIGNMENT 3 (LECTURE 7–10)

Included:
- 10 separate .js files, one for each assignment question.
- Strict mode used wherever applicable.
- Comments explain logic, hoisting, scope, errors, and debugger observations.
- No external libraries or frameworks.

Run with Node.js:
  node Q1_Dynamic_Data_Parser.js

Replace the filename to run another question.

Browser notes:
- Q6 uses prompt() when run in a browser. In Node.js, it uses the default row count of 5.
- For debugging questions, open the file in VS Code, set breakpoints or use the included debugger; statements, then run with the JavaScript debugger.
