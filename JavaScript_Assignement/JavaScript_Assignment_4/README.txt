JAVASCRIPT ASSIGNMENT 4 — CLASSES, OBJECTS, FORMS AND REGEXP

Contains 9 separate JavaScript files, one for each question in the supplied PDF.

Run Node.js-compatible questions:
  node Q1_Ecommerce_Product_Manager.js
  node Q3_Library_Management_System.js
  node Q6_Employee_Management_System.js
  node Q9_Shopping_Cart_Total.js

Browser-based questions:
  Q2, Q4, Q5, Q7 and Q8 use DOM forms.
  Open a blank HTML page in a browser, then load the relevant .js file
  using a script tag or paste its contents into the browser console.

Example HTML:
  <script src="Q2_Student_Form_Validator.js"></script>

No external libraries or frameworks are used. Each file includes comments.
