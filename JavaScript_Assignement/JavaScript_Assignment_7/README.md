# Assignment 7 – DOM Manipulation

This submission contains all 9 practical questions from the provided PDF.

## Folder structure
Each question has its own folder containing:
- `index.html` – page structure
- `style.css` – page styling
- `script.js` – JavaScript solution for that question

## How to run
1. Extract the ZIP file.
2. Open any question folder (for example, `Q1_Product_List`).
3. Open `index.html` in a modern web browser.
4. Test the feature described in the assignment.

No frameworks or external JavaScript libraries are used. The image gallery uses six remote sample images from Picsum, so an internet connection is needed for those images to load.

## Questions included
1. Dynamic Product List Manager (event delegation, inline editing, outside-click save)
2. Live Character Counter (100-character limit, warning colors, reset)
3. Multi-Step Form (three steps, validation, back/next, summary)
4. Theme Switcher (Light, Dark, Blue using `setAttribute()`)
5. Image Gallery with Modal (six images, outside-click close, `stopPropagation()`)
6. Real-Time Student Table Filter (case-insensitive input filtering)
7. Mouse Path and Coordinates Logger (400×400 area, coordinates, double-click red dot)
8. Custom Dropdown (no `<select>`, outside-click close in capturing phase)
9. Form Submit Blocker (required validation, `preventDefault()`, live errors, success message)
