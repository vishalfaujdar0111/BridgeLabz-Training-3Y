JAVASCRIPT ASSIGNMENT 5 — FUNCTIONS, CALLBACKS, PROTOTYPES AND CLOSURES

This folder contains 9 separate .js files, one for each question.

Run any file using Node.js:
  node Q1_Callback_Greet_User.js

Replace the filename to run another question.

Notes:
- Core JavaScript ES6+ only; no external libraries or frameworks.
- Q3's arrow-function `this` output can differ by execution context. In Node.js
  CommonJS/module context, top-level `this.name` is undefined as shown.
- Q8 extends Array.prototype as required by the assignment. In production
  projects, modifying built-in prototypes should generally be avoided.
